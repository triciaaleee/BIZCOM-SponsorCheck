Quick rules
  • One company per row.
  • Two columns only: company_name and industry_code.
  • Industry code is optional but speeds up classification. See the sponsor directory for the full list of codes.
  • No merged cells, no header notes, no totals row.
  • Save as CSV (UTF-8) before uploading. In Excel: File › Save As › CSV UTF-8.

# Company Status Industry Reason
What each status means
  • Clear: previously approved by BIZCOM, safe to approach.
  • Caution: approaching the 30-day outreach cap.
  • Alumni: alumni-affiliated, needs OAR clearance.
  • Blocked: banned per Annex A or B, or company has closed.
  • Cooldown: 30-day outreach cap reached, wait for next cycle.
  • Unverified: new company, BIZCOM has not vetted yet.
Tips
  • One company per row. Suffixes like "Pte Ltd" are auto-stripped.
  • Include an industry_code column to skip auto-classification.
  • Caps are enforced before submit. Trim if you exceed.
